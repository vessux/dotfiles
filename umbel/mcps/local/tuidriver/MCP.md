# tuidriver

Drives terminal-UI sessions over MCP. Exposes tools to start/list/close
sessions, send keystrokes, snapshot the screen, wait for text, resize,
and inspect cursor state.

## Prereq

`tuidriver` binary must be on `PATH`. Verify with `which tuidriver`.
